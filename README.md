# ISTQB CTFL v4.0 Interactive Study Guide

Practice-first, fully static learning guide for the **ISTQB Certified Tester Foundation Level (CTFL) v4.0** certification. No login, no backend — progress saved in your browser.

## Run locally

npm install
npm run dev   # http://localhost:3000

## Deploy (Vercel)

npx vercel    # no env vars needed

## What's inside

- 6 chapters · 64 learning objectives · Practice-first approach
- Concept → Quiz → Interactive Exercise → Complete
- 4 mock exam sets (A/B/C/D) · 40 questions each · 60-minute timer
- Pass threshold: 26/40 (65%)
- 100% static — zero backend, zero auth
- Pairs with the CT-AI v2.0 guide for full ISTQB AI testing track
